                                                                      SALES DATA ANALYSIS
PROJECT DESCRIPTION:

This project focuses on analyzing sales data using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn. The objective of this analysis is to identify sales trends, top-performing products, regional performance, customer purchasing behavior, and overall business insights through data visualization and exploratory data analysis (EDA).

THE PROJECT DEMONSTRATE PRACTICAL SKILL IN:

▪️ Data Cleaning
▪️ Data Analysis
▪️ Data Visualization
▪️ Business Insight Generation

TECHNOLOGIES USED:

◦ Python
◦ NumPy
◦ Pandas
◦ Matplotlib
◦ Seaborn

PROJECT WORKFLOW:

1️.Data Collection & Loading

The dataset is imported using Pandas for further analysis.

2️.Data Cleaning & Preprocessing

Checked missing values
Verified data types
Converted order dates into datetime format
Extracted month information for trend analysis

3️.Exploratory Data Analysis (EDA)

Performed detailed analysis to understand:
Region-wise sales
Category-wise revenue
Product performance
Monthly sales trends
Customer purchase behavior

4️.Data Visualization

Created multiple visualizations for better understanding:
Pie Chart
Bar Chart
Line Plot
Histogram
Correlation Heatmap

1.Total Sales Analysis: Calculated the overall revenue generated from sales.

3.Category-wise Revenue Analysis: Compared product categories based on total sales.

KEY INSIGHTS

- The dataset is clean and reliable with no missing values or duplicate records.
- Sales performance varies across different regions.
- Certain product categories generate higher sales than others.
- A few products contribute significantly to total revenue.
- Higher quantity sold leads to increased total sales.
- Product price has a positive impact on sales revenue.
- These insights can help improve inventory planning and business decision- making.
